# lit-radar · 科研文献查询器

面向膜分离、微塑料和高级氧化研究者的中文文献检索网页。可以按研究方向和期刊分区缩小范围，用关键词或 DOI 定位论文，再收藏待读条目、标记阅读进度。

**[打开在线查询器](https://mhl533.github.io/lit-radar/)** · [报告问题或纠正条目](https://github.com/MHL533/lit-radar/issues)

## 怎样查一篇论文

以查找**催化膜活化过一硫酸盐（PMS）**的研究为例。

1. 在「领域与方向」中选择「膜分离」，再点「催化膜」。
2. 在搜索框输入 `peroxymonosulfate`。搜索会匹配标题、中文要点、期刊名及缩写、DOI 和作者单位，忽略英文大小写。已知 DOI 时，可以直接粘贴 DOI 编号。
3. 用「上线日期」或「中科院分区」缩小范围。打算稍后阅读的论文可以收藏，读完后点「已读」。下次用「★ 收藏」或「未读」筛选即可。

## 个人账户、研究方向与反馈

开通云账户后，点击「登录 / 注册」并选择「注册」，填写邮箱和密码，选择自己关注的研究方向。完成邮箱验证后，使用同一邮箱登录。进入「我关注的方向」可以直接浏览相关论文。点击右上角账户可以修改昵称和方向。同一账户在不同设备上共享收藏和已读标记。

使用「反馈」提交账户问题、功能建议或文献纠错。云端会把已登录用户的反馈关联到本人账户，访客也可以匿名提交。维护者可以从 Supabase 的 `feedback` 表查看记录。网站未配置云服务时，可使用「本机档案」在当前浏览器保存偏好。

### 为自己的站点启用邮箱登录

1. 在用于本站的 Supabase 项目中执行 [建表脚本](supabase/schema.sql)，启用 Data API 并将 `public` 加入开放的数据库模式。脚本为个人资料、阅读标记和反馈设置行级权限。
2. 在 **Authentication** 中启用 Email、允许新用户注册并开启邮箱确认。在 **URL Configuration** 中将 Site URL 和允许的回跳地址设置为站点首页。本仓库的地址为 `https://mhl533.github.io/lit-radar/`。
3. 面向公众开放注册前，配置可用的 SMTP 发信服务，以便访客收到确认邮件。Supabase 默认邮件服务仅向项目团队成员的地址发信。[发信服务说明](https://supabase.com/docs/guides/auth/auth-smtp)
4. 将项目 URL 和客户端公开密钥（publishable key 或 anon key）分别填入 [config.js](config.js) 的 `supabaseUrl` 和 `supabaseAnonKey`，再发布页面。服务端密钥只保存在服务端。
5. 用一个测试邮箱注册并验证。换一个浏览器登录同一账号，检查「我关注的方向」和收藏能否恢复，再提交一条「账户与登录」反馈，核对后台记录的 `user_id`。

### 手机、微信和 QQ 登录

登录框会显示中国大陆手机号验证码、微信扫码和 QQ 登录的开通状态。首次通过这些方式登录后，可以在「我的账户」选择研究方向。已有邮箱账户的用户应先按原方式登录，再从账户设置绑定手机号、微信或 QQ。资料、收藏和反馈继续使用同一 Supabase 用户 ID。

手机号入口读取项目的短信验证状态。微信和 QQ 分别通过独立的 OIDC 登录连接接入。待开通的按钮会显示状态，开通后即可使用。管理员可按 [中国用户登录接入与验收](docs/china-sign-in.md) 配置短信、授权回调及应用凭据。

## 数据来源与更新

文献按「领域/月份」分片保存在 [data/](data/) 目录，网页按需加载。分片里重复出现的期刊、单位、关键词只存一次（格式说明见 [scripts/lib.py](scripts/lib.py)），并带内容哈希，浏览器再次打开时可直接用缓存。

脚本从 Crossref 获取论文：一是逐篇扫描约 80 种核心期刊，二是按各细分方向的关键词检索。只保留 [中科院 2025 年版 1–2 区期刊](scripts/journals_cas2025.csv) 的论文，用 [标题规则](scripts/rules.py) 归类，按 DOI 去重。作者单位、关键词和主题取自 OpenAlex。期刊分区表和 JCR 影响因子整理自 [ShowJCR](https://github.com/hitfyd/ShowJCR) 收录的公开数据。

| GitHub Actions 任务 | 何时运行 | 做什么 |
| --- | --- | --- |
| [Daily update](.github/workflows/daily.yml) | 北京时间 7:05、11:05、18:05，另每 3 小时补跑一次 | 收录最近几天新登记的论文，补全单位与关键词，把新增条目写入 `data/latest.json` |
| [Maintain library](.github/workflows/maintain.yml) | 每天凌晨 2:40，或手动运行 | 分批补全较早论文的 OpenAlex 数据；手动选 `reclassify` 可按最新规则重新归类全库 |
| [Backfill library](.github/workflows/backfill.yml) | 手动运行 | 按出版年份并行补录，再合并提交 |

推送任务通过 [scripts/push.py](scripts/push.py) 读取自上次推送以来的新增论文，并把中文要点写回。

## 本地运行

安装 Git 和 Python 3 后，在终端运行以下命令。最后一条命令会在本机启动静态文件服务器。

```bash
git clone https://github.com/MHL533/lit-radar.git
cd lit-radar
python -m http.server 8000 --bind 127.0.0.1
```

在浏览器打开 [本地查询器](http://127.0.0.1:8000/)。如果系统使用 `python3` 命令，请将最后一行的 `python` 换成 `python3`。
